# Лабораторна робота №1

**Дисципліна:** Розробка програмного забезпечення на платформі Java

**Тема:** Сучасні можливості Java та підхід Data-Oriented Programming (DOP).

## Опис проєкту

У цьому проєкті створено програму для обробки замовлень. Вона дозволяє працювати з чотирма станами замовлення: очікування обробки, оплата, відправлення та скасування. Для кожного стану програма формує повідомлення з відповідною інформацією про замовлення. Наприклад, для оплаченого замовлення вказується сума та ідентифікатор платежу, а для відправленого код відстеження і дата відправлення. Також у програмі передбачено перевірку даних, щоб уникнути неправильних або порожніх значень.

## Визначення варіанта

Варіант визначено за порядковим номером у списку групи.

**Номер у списку:** 9

**Розрахунок:** V = 9 mod 3 = 0

**Варіант V=0:** Система управління замовленнями.

## Тестування

Для перевірки роботи програми створено юніт-тести з використанням JUnit 5. Тести перевіряють правильність обробки всіх чотирьох станів замовлення, а також виникнення винятків у випадку некоректних даних.

Усього реалізовано 15 тестів, які успішно пройшли перевірку.

## Запуск тестів

Для запуску тестів необхідно мати встановлені Java 21 та Maven.

Після завантаження проєкту потрібно відкрити термінал у кореневій папці проєкту та виконати команду:

`mvn test`

Після виконання команди Maven запускає тести та виводить результати перевірки.
